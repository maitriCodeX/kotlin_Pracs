# Practical 1 – Kotlin Programming Concepts

## Aim

To develop a Kotlin program demonstrating various fundamental programming concepts, including variables, data types, type conversion, input/output, control flow, functions, recursion, arrays, collections, classes, constructors, operator overloading, and matrix operations.

## Technologies Used

* **Language:** Kotlin
* **IDE:** Android Studio / IntelliJ IDEA
* **Concept:** Kotlin Programming

---

## Practical List

### 1.1 Store & Display Values in Different Variables

Demonstrates the declaration and display of variables using different Kotlin data types:

* Integer (`Int`)
* Double (`Double`)
* Float (`Float`)
* Long (`Long`)
* Short (`Short`)
* Byte (`Byte`)
* Character (`Char`)
* Boolean (`Boolean`)
* String (`String`)

---

### 1.2 Type Conversion

Demonstrates type conversion between different data types in Kotlin.

Conversions performed:

* Integer → Double
* String → Integer
* String → Double

---

### 1.3 Scan Student's Information

Demonstrates taking student information as input from the user and displaying the entered data.

Information includes:

* Student Name
* Enrollment Number
* Branch
* Semester
* Other student details

---

### 1.4 Check Odd or Even Numbers

Demonstrates the use of conditional expressions and control flow to determine whether a given number is **odd or even**.

The result is displayed directly using the `println()` method.

---

### 1.5 Display Month Name

Demonstrates the use of Kotlin's `when` expression.

The program accepts a month number from the user and displays the corresponding month name.

Example:

```text
Input: 5
Output: May
```

---

### 1.6 User-Defined Function

Demonstrates the creation and use of a user-defined function to perform arithmetic operations on two numbers.

Operations include:

* Addition
* Subtraction
* Multiplication
* Division

---

### 1.7 Factorial Calculation Using Recursion

Demonstrates **recursion** by calculating the factorial of a given number.

For example:

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

The function repeatedly calls itself until the base condition is reached.

---

### 1.8 Working with Arrays

Demonstrates different array operations and looping techniques in Kotlin.

Concepts covered:

* `Arrays.deepToString()`
* `contentDeepToString()`
* `IntArray.joinToString()`
* `range`
* `downTo`
* `until`
* Array traversal
* Array manipulation
* Sorting without built-in functions
* Sorting using built-in functions

---

### 1.9 Find Maximum Number from ArrayList

Demonstrates working with an `ArrayList` of integers.

The program finds and displays the **maximum value** present in the ArrayList.

---

### 1.10 Class and Constructor Creation

Demonstrates object-oriented programming concepts by creating a `Car` class with properties such as:

* Type
* Model
* Price
* Owner
* Miles Driven

Functions are implemented to:

* Get car information
* Display car information
* Find the original car price
* Calculate the current car price

This practical demonstrates the use of **classes, constructors, properties, and member functions** in Kotlin.

---

### 1.11 Operator Overloading and Matrix Operations

Demonstrates **operator overloading** using a `Matrix` class.

The program performs:

* Matrix Addition
* Matrix Subtraction
* Matrix Multiplication

The `toString()` function is also overloaded to provide customized matrix output.
